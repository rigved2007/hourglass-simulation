Contact model

Spring–dashpot contacts with Coulomb friction, matching LAMMPS pair granular hooke. Soft contacts make the flow about 10% (2D) to 13% (3D) faster; the theory line includes that factor. 3D starts with soft contacts so it runs closer to real time.

Magnetism

Share of grains that are ferromagnetic; the rest are non-magnetic (like Sunday et al.'s steel–brass mixtures). Magnetic grains are tinted blue.
0° points along gravity, 90° is horizontal. Induced dipoles only care about the axis, so 0° and 180° are the same.
Off: each grain's moment comes from the applied field only. On: the field from neighbouring grains is added, so grains in a chain along the field are magnetised more strongly and grains side by side less. This strengthens chains and lets them bundle. Because the forces grow, contacts are stiffened to match, so steel runs up to about 3× slower; magnetite (weaker) much less.

Background sweeps

Each sweep reruns the current glass in background threads (several at once). Thorough sweeps refill the glass from the top so the flow reaches a steady rate, measure it over a fixed window, and repeat each point with different random fills to give error bars.

Reading the field from the hourglass

A finished sweep is turned into a calibration: the graph and formulas run backwards, from what the hourglass shows (flow rate, emptying time) to the field that must be acting. The live run is placed on it using the ordinary-sand twin above.

The GPU model follows every grain with the same contact law as the grain modes, so magnetism, endless sand and replay all work; the grain size slider below sets how fine the sand is (smaller = more grains). It needs WebGPU on real graphics hardware; without it the continuum model is used.
